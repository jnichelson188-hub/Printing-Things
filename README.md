# Printing Things - 3D Printing Store

A full-featured e-commerce store for selling 3D prints, 3D models, and electronics.

## Features

- 🛍️ Product Catalog (3D Prints, Models, Electronics)
- 🛒 Shopping Cart
- 💳 Payment Integration (PayPal, Stripe, Visa/Mastercard)
- 👤 User Accounts & Authentication
- 📦 Order Management
- 📥 File Upload (3D Models)
- 🔒 Admin Dashboard
- 📧 Email Notifications

## Tech Stack

- Frontend: HTML, CSS, JavaScript
- Backend: Node.js + Express
- Database: SQLite
- Payments: PayPal & Stripe Integration

## Getting Started

1. Clone the repository
2. Install dependencies: `npm install`
3. Configure payment keys in `.env`
4. Run the server: `npm start`
5. Visit `http://localhost:3000`
